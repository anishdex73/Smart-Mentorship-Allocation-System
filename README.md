# Intelligent Smart Mentorship Allocation Dashboard

A working HTML/CSS/JavaScript prototype for the DSA-II PBL project.

## Run
Open `index.html` in a modern browser.

## Current working features
- Overview dashboard
- Mentor directory
- Mentee directory
- Add mentor / mentee forms
- Search and department filtering
- Compatibility scoring
- Capacity-aware matching
- Allocation results
- Why-this-match detail
- Bipartite-style mentorship network visualization
- Analytics
- Methodology / DSA roadmap
- Responsive layout

## Current scope
This is intentionally a dashboard prototype. Advanced algorithms such as Gale-Shapley, dynamic programming, backtracking and branch & bound are shown as future extension points rather than falsely claimed as implemented.
